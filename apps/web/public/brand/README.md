# Local brand assets

`clan-logo.webp` is the neutral “Your Clan” placeholder. Administrators can replace
it independently for ordinary and hardcore worlds. Local `favicon.webp` is
derived from that placeholder. `skull.webp` is the bundled
hardcore-mode icon.

`github-mark.webp` is the Primer Octicons GitHub mark under the included
[MIT license](github-mark.LICENSE.txt). The footer uses a local crop of ko-fi-blue.webp beside its support link.
That official button comes from https://more.ko-fi.com/brand-assets (retrieved
11 October 2026); it is bundled locally rather than fetched by the browser. See [asset attribution](../../../../docs/assets.md).
